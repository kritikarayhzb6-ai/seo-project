Search visibility review

SEO audit, in plain English.

Website: Digi DracuaaAudit date: 10 September 2026Pages reviewed: 5

The website has a clear agency proposition, consistent navigation, descriptive page copy, and basic search metadata. Its main SEO weaknesses were technical HTML duplication, competing headings, a broken JavaScript reference, incomplete crawl files, weak social metadata, and placeholder business details.

The highest-risk structural issues have been corrected. The remaining work depends on production information and live verification, including the real contact details, final domain, form delivery, Search Console, analytics, performance, indexing, and backlinks.

What needs attention

01. Contact form is not connected

The form validates in the browser and displays a success message, but it does not send the enquiry to an email service, CRM, server, or form provider.

Recommendation: Connect it to a trusted endpoint and show success only after the request succeeds.

02. Placeholder business details remain

The phone number is still +91 00000 00000, and social links point to #. This weakens trust and local SEO.

Recommendation: Add verified phone, email, address, service area, hours, and social profiles.

03. Confirm the production domain

Canonical URLs and the sitemap currently use digidracua.vercel.app.

Recommendation: If a custom domain is used, update canonicals, Open Graph URLs, sitemap URLs, and redirects.

04. Service intent is too broad

One Services page combines websites, SEO, paid media, automation, video, advertising, Android apps, and desktop apps.

Recommendation: Create dedicated pages for SEO, website development, digital marketing, and app development.

05. Portfolio cards are not destinations

Portfolio cards use href="#", so visitors cannot inspect a case study.

Recommendation: Give each project a real page with the problem, work, timeline, results, and images.

06. Structured data is missing

No business, service, website, or breadcrumb JSON-LD was identified.

Recommendation: Add verified LocalBusiness or Organization schema and validate it with Google's Rich Results Test.

Fixes already made

  • Removed duplicate introductory content and competing H1 elements.
  • Rebuilt the duplicated About page as one valid HTML document.
  • Corrected the shared script reference and added defer.
  • Repaired the homepage project image markup and added dimensions and lazy loading.
  • Improved page titles, descriptions, local relevance, and Open Graph metadata.
  • Added robots.txt and sitemap.xml.

How to measure it

Verify the production domain in Google Search Console and submit the sitemap. Track impressions, organic clicks, average position, click-through rate, queries by page, indexed pages, excluded pages, crawl issues, and Core Web Vitals.

Business metrics

Measure qualified organic leads, contact completion rate, calls, proposal requests, customers, and revenue from organic traffic. The primary conversion should be a qualified enquiry, not a page view.

Useful formulas

Lead rateQualified organic leads / organic sessions x 100
Cost per leadSEO investment / qualified organic leads
Close rateCustomers from organic leads / total organic leads x 100
